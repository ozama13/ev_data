
Electric Vehicle Trends Data Pipeline 🚗⚡

📌 Project Overview

This project extracts, cleans, stores, and visualizes electric vehicle trends data using a cloud-based pipeline. The goal is to automate data ingestion, transformation, and visualization for insights into EV adoption.

✅ Automated Data Pipeline – Python & SQL
✅ Cloud Storage – AWS RDS (PostgreSQL)
✅ Data Cleaning & Transformation – Pandas in Visual Studio Code
✅ Database Management – SQLAlchemy for querying PostgreSQL
✅ Security & Access Control – AWS IAM for user permissions
✅ Interactive Dashboard – Tableau

🛠 Tech Stack

Data Cleaning & Transformation: Python, Pandas
Database & Storage: AWS RDS (PostgreSQL)
Querying & ORM: SQLAlchemy, SQL
Cloud Security: AWS IAM (User & Group Privileges)
Visualization: Tableau
📊 Project Workflow

1️⃣ Data Extraction & Cleaning

Extracted real-world EV dataset
Cleaned & transformed using Python (Pandas) in Visual Studio Code

2️⃣ Database Setup & Connection

Created an AWS RDS PostgreSQL instance
Defined tables and loaded data into the database
Configured IAM user group & privileges for database security

3️⃣ Querying & Analysis

Connected SQLAlchemy to AWS PostgreSQL
Queried and analyzed EV data using SQL

4️⃣ Visualization & Insights

Connected AWS RDS to Tableau
Created an interactive dashboard to visualize EV trends
